    400 js, react (요청 자체 문제) 
    500 backend(요청 정상, 서버문제)

    Dom: html을 객체로 만들어주는, html과 js
    api: 프로그램과 연결하는 인터페이스, html과 java
    캐싱: 한번 방문했던 사이트 특정파일을 브라우저에 저장하고 다음에 방문할때 서버에 저장된 파일을 사용하는 기술
    SPA: 처음 단 하나의 HTML페이지 받아오고 다른 메뉴 클릭해도 페이지 전체를 새로 불러오지않음
    
    JSX: HTML + JS 혼합문법 제공
    JSP: HTML+JAVA 혼합문법 제공

    node.js: java처럼 js가 혼자서 실행가능한 환경(런타임)
    npm: 스프링 gradle처럼 외부 라이브러리 설치/관리 프로그램
        - node.js에 npm포함

    cd.. : 폴더 뒤로가기


1. node_modules: 설치된 라이브러리 모은 폴더
2. public: img/js/동영상/logo 정적 파일 모은 폴더
3. src->main.jsx: 리액트 실행 진입점 파일
4. index.html: 리액트는 SPA(싱글 페이지 어플리케이션)이라서 HTML이 1개
5. pakage.json: 설치전 라이브러리(의존성) 담고있는 파일
- 리액트 시작: npm run dev
